# ⚔️ Nightreign Relic Extractor & Vessel Loadout Manager

> **The ultimate standalone loadout builder, relic extractor, and in-game HUD overlay for Elden Ring: Nightreign.**  
> *v1.5.0 • Standalone Windows Executable • Native .NET 4.8 • Zero Dependencies • 100% Safe*

---

## ✦ Overview
**Nightreign Relic Extractor & Vessel Loadout Manager** is a modern, standalone desktop tool designed specifically for *Elden Ring: Nightreign* (`NR0000.co2` save files). 

It empowers you to inspect your entire relic inventory, construct optimized character vessel builds (Urn, Goblet, Chalice, etc.) with color affinity matching, hotkey-swap loadouts in-game via a sleek transparent overlay HUD (**F10**), and safely inject your custom builds directly into your save file with automatic MD5 checksum recalculation and automatic 4-backup rotation!

---

## ✦ Key Features
* 🎮 **Dark Fantasy Gamer HUD**: Completely overhauled modern UI inspired by Elden Ring, Discord, and Steam UI with deep void backgrounds, card panels, and glowing affinity socket rings.
* ⚔️ **In-Game Transparent Overlay (F10)**: Press **F10** anytime while playing to pull up a semi-transparent HUD overlay. Switch presets on the fly without alt-tabbing!
* 🏺 **Vessel Loadout Builder**: Support for all 10 characters and all 7 vessel types. Visually configure your 3 Normal slots and 3 Deep slots with live affinity matching (Red, Blue, Yellow, Green, Any) and comprehensive in-game passive effect descriptions.
* 🛡️ **1-Click Save File Injection & Auto-MD5 Recalculation**: 100% safe. Whenever you equip a build, the tool automatically recomputes the internal MD5 checksum required by the game engine—preventing "Save Data Corrupted" warnings.
* 🔄 **4-Backup Timestamped Rotation**: Automatically creates timestamped `.bak` backups before every single save write (keeps up to 4 historical backups, automatically rotating the oldest).
* 🧠 **AI Build Architect (ChatGPT / Claude)**: 1-click export of your current relic collection into optimized prompts for ChatGPT or Claude to design Meta, Fun, Support, or Hybrid builds, with instant JSON copy/paste import.
* 📊 **Relic Inventory Extractor**: Decrypts and exports your full relic inventory to CSV and styled Excel (`.xlsx`) spreadsheets with full multi-effect breakdown and values.
* 🌐 **Multi-Language Support**: Fully translated in **English**, **Français**, and **العربية** (with right-to-left layout formatting).
* ⚡ **Zero Dependencies & Portable**: A single standalone executable (`NightreignRelicExtractor.exe`). Requires no external mod loaders, no DLL injection, no Python, and no extra runtimes.

## ✦ How to Install & Use
1. **Download & Extract**: Download `NightreignRelicExtractor-v1.5.0.zip` from the Files tab and extract `NightreignRelicExtractor.exe` anywhere (e.g. Desktop or game tools folder).
2. **Run the App**: Double-click `NightreignRelicExtractor.exe`. It will automatically detect your active Nightreign save file in `%APPDATA%\Nightreign\`.
3. **Build or Equip a Loadout**:
   * Head to the **Vessel Builder** tab, select your character and vessel.
   * Click **Change...** on any slot to search, filter by affinity, and select from your collected relics.
   * Click **Equip & Save to Save File** to inject the loadout into your save.
4. **In-Game Activation**: In Elden Ring: Nightreign, quit to the Main Menu and click **Continue** or **Load Game**. Your character will load with the newly equipped relics!
5. **In-Game Overlay (F10)**: While the tool is running, press **F10** anytime in-game to toggle the overlay and switch saved builds instantly.

## ✦ Safety & Multiplayer Compatibility
> **Is this safe to use online?**  
> Yes! Nightreign Relic Extractor operates entirely at the save-file level (`NR0000.co2`). It does NOT hook into game memory, does NOT alter executable code, and does NOT run active background hooks that trigger Anti-Cheat.  
> Furthermore, other players in co-op sessions do NOT need this tool installed—your equipped relics are standard in-game items stored directly in your genuine save data.
