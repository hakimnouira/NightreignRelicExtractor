================================================================================
  NIGHTREIGN RELIC EXTRACTOR & VESSEL LOADOUT MANAGER (v1.5.0)
  For Elden Ring: Nightreign (NR0000.co2 Save Files)
================================================================================

A standalone, safe, and powerful loadout manager and relic extractor for Elden Ring: Nightreign.

QUICK START:
1. Extract "NightreignRelicExtractor.exe" anywhere (e.g. Desktop or game tools folder).
2. Double-click to run. It automatically locates your active Nightreign save file (NR0000.co2).
3. Switch between tabs:
   - [Relic Extractor]: View all collected relics and export to CSV / Excel.
   - [Vessel Builder]: Inspect active/inactive vessels for all 10 characters, equip relics with affinity matching, and save directly to your file.
   - [Loadouts & Overlay]: Browse presets, hotkey switch builds with F10 in-game, or snapshot your active loadout.

KEY FEATURES:
* Dark Fantasy HUD: Sleek Elden Ring & Discord-inspired aesthetic with color-coded affinity sockets.
* In-Game Overlay HUD (F10): Press F10 while playing to pop up a transparent HUD and switch loadouts without alt-tabbing.
* Instant Save Injection: 1-click apply updates your save file directly. Just quit to Main Menu and hit "Continue" to play with new relics!
* Absolute Safety: Recalculates the internal MD5 hash (preventing "Save Data Corrupted" errors) and maintains an automatic 4-backup timestamped rotation (.bak).
* AI Build Generator: Export your full relic inventory to ChatGPT/Claude with structured prompts to discover optimized character builds.
* Multi-Language: English, French, and Arabic (with RTL formatting).
* Zero Dependencies: Runs natively on Windows 10/11 (.NET Framework 4.8). No external mod loaders or DLL injectors needed.

HOTKEYS:
- F10: Toggle In-Game Overlay HUD (customizable / toggleable)
- ESC: Close Overlay

DISCLAIMER:
This tool modifies local save files. While automatic 4-stage backup rotation is built-in, always keep manual backups of your saves in %APPDATA%\Nightreign\.
